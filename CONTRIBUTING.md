# 🤝 Como Contribuir para o LegendClient

Agradecemos o interesse em ajudar a evoluir o **LegendClient (Legend Online By Peta)**! O projeto é construído com base no feedback direto dos jogadores.

## 📌 Formas de Contribuição

### 1. Reportando Bugs Técnicos
Se encontrou alguma falha visual, erro de execução no Flash ou problema na inicialização:
- Verifique se o bug já não foi reportado na aba de [Issues](https://github.com/petadeteta22/legend-online-by-peta/issues).
- Ao criar uma Issue, forneça detalhes como a versão do Windows (10 ou 11), a taxa de FPS configurada e o servidor afetado.

### 2. Sugerindo Novos Recursos
Tem uma ideia para o launcher ou para a **Central de Ferramentas**?
- Abra uma proposta na aba de [Discussions](https://github.com/petadeteta22/legend-online-by-peta/discussions) ou envie uma Issue com a etiqueta `enhancement`.

### 3. Apoio ao Projeto
O desenvolvimento e a infraestrutura de atualizações do cliente dependem da comunidade.
- Saiba como apoiar e liberar os recursos exclusivos de apoiador acessando o [Site Oficial](https://www.legendclient.com.br/).
